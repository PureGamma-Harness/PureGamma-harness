# 简洁工作空间

[English](README.md) | 中文

这个可选外观插件为 PureGamma 提供石墨色深色主题、米白色浅色主题、蓝色选中和焦点强调、紧凑导航及抬高的输入区域。它只改变现有控件的外观，不改变会话、凭据、模型选择或工具。文本和代码使用用户保存的字体偏好。两套调色板中，主要文字、次要文字、选中标签及发送控件的配色对均达到 WCAG AA 对比度要求。

插件跟随已有的浅色和深色主题选择，遵循减少动态效果设置，并保留原生侧边栏折叠、编辑器滚动、菜单锚点及窗口控件避让。展开的侧边栏控件与窄屏输入区域圆角分别处理；触摸输入时编辑器字号至少为 16px。能力导航由[插件导航](../dsh-plugin-rail/README.zh.md)提供。

PureGamma 安装器启用此插件，并停止启用之前的像素字体及蓝色气泡插件。它们的依赖和设置保留，可手动重新启用。在插件管理器中禁用此插件即可恢复原生外观。

在仓库根目录运行 `node --test pg-harness/plugins/dsh-quiet-workspace/plugin.test.mjs pg-harness/plugins/dsh-plugin-rail/plugin.test.mjs`，检查外观及导航。`preview.html` 调色板夹具可预览两种主题和窄屏布局；它不是运行中的应用，也不是端到端测试。
